## What your Cursor setup is doing

The pattern in [.cursor/hooks.json](.cursor/hooks.json) is a project-level hook system:

- It listens to Cursor lifecycle events:
  - `beforeSubmitPrompt`
  - `afterAgentResponse`
  - `stop`
- Each event runs a shell script:
  - [.cursor/hooks/log-prompt.sh](.cursor/hooks/log-prompt.sh)
  - [.cursor/hooks/track-response.sh](.cursor/hooks/track-response.sh)
  - [.cursor/hooks/flush-response.sh](.cursor/hooks/flush-response.sh)

Those scripts:
- read the JSON payload from stdin
- extract the prompt / response / session ID
- store the data in a local log directory
- append markdown entries so each conversation is kept in a file

So the idea is: “hook into the AI lifecycle and persist it locally”.

---

## The VS Code equivalent

There is no direct native equivalent of Cursor’s `hooks.json` in plain VS Code.

The closest thing is:

1. A VS Code extension using the Chat API
2. Or workspace-level instructions/config, which is not the same as lifecycle hooks

> Native VS Code does not expose a public hook like “beforeSubmitPrompt” or “afterAgentResponse” for Copilot’s built-in chat. You can only intercept behavior for things you build yourself, such as a custom chat participant.

---

## Best VS Code approach

If your goal is “log prompts and responses in a repo”, do this:

- create a small extension
- register a custom chat participant
- when the user sends a prompt, write it to a log file
- when the response is streamed back, append that too

Example:

```ts
import * as vscode from 'vscode';
import * as fs from 'fs/promises';
import * as path from 'path';

export function activate(context: vscode.ExtensionContext) {
  const logDir = path.join(context.extensionPath, '.ai-logs');
  const logFile = path.join(logDir, 'session.md');

  const participant = vscode.chat.createChatParticipant('my.logger', async (request, context, stream, token) => {
    await fs.mkdir(logDir, { recursive: true });

    const entry = `
## Prompt
${request.prompt}

## Context
${context.history.length} prior turns
`;

    await fs.appendFile(logFile, entry);

    const answer = `I logged your prompt and I can help with it.`;
    stream.markdown(answer);

    await fs.appendFile(logFile, `
## Response
${answer}
`);
  });

  context.subscriptions.push(participant);
}
```

And in `package.json`:

```json
{
  "activationEvents": ["onChatParticipant:my.logger"],
  "contributes": {
    "chatParticipants": [
      {
        "id": "my.logger",
        "name": "logger"
      }
    ]
  }
}
```

## If you want repo-level AI behavior without an extension

VS Code also supports things like:

- `.github/copilot-instructions.md`
- workspace settings
- prompt files / custom instructions

But that is not a hook system; it is instruction/configuration, not event logging.

---

## Recommendation

If you want “Cursor-like project automation” in VS Code:

- For logging: use a small extension
- For repo guidance: use Copilot instruction files
- For auth/tooling automation: use MCP or workspace commands
