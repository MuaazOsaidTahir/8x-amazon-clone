- button click fires once

- you see the callback run twice in the console / debugger

That is why it feels like the cart update is happening twice.

## Correct pattern

Use an immutable update like this:

```tsx
const addToCart = (product: Product) => {
  setCart((prev) => {
    const current = prev[product.id];

    return {
      ...prev,
      [product.id]: current
        ? { ...current, quantity: current.quantity + 1 }
        : { product, quantity: 1 },
    };
  });
};
```

And for remove:

```tsx
const removeFromCart = (product: Product) => {
  setCart((prev) => {
    const current = prev[product.id];
    if (!current) return prev;

    const nextQty = current.quantity - 1;

    if (nextQty <= 0) {
      const { [product.id]: _, ...rest } = prev;
      return rest;
    }

    return {
      ...prev,
      [product.id]: { ...current, quantity: nextQty },
    };
  });
};
```

I will show the React pattern for collecting form values without touching the DOM directly or wiring an onchange handler to every field.## React way: use a single form state object and submit the form data

Instead of reading from the DOM, keep the field values in React state and read them when the form is submitted.

```tsx
import { useState, type FormEvent } from "react";

export default function LoginPage() {
  const [formData, setFormData] = useState({
    name: "",
    email: "",
    password: "",
  });

  const submitForm = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();

    console.log(formData);
    // send formData to API here
  };

  return (
    <form onSubmit={submitForm}>
      <input
        type="text"
        value={formData.name}
        onChange={(e) =>
          setFormData((prev) => ({ ...prev, name: e.target.value }))
        }
      />

      <input
        type="email"
        value={formData.email}
        onChange={(e) =>
          setFormData((prev) => ({ ...prev, email: e.target.value }))
        }
      />

      <input
        type="password"
        value={formData.password}
        onChange={(e) =>
          setFormData((prev) => ({ ...prev, password: e.target.value }))
        }
      />

      <button type="submit">Submit</button>
    </form>
  );
}
```

### Why this is the correct React approach
- React owns the form state.
- No `document.querySelector(...)`
- No direct DOM read
- You get values from `formData` when the user submits

## Without using `onChange` on every field
If you want to avoid writing `onChange` for each input, you can use a single handler with the input name:

```tsx
import { useState, type FormEvent } from "react";

export default function LoginPage() {
  const [formData, setFormData] = useState({
    name: "",
    email: "",
    password: "",
  });

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    const { name, value } = e.target;

    setFormData((prev) => ({
      ...prev,
      [name]: value,
    }));
  };

  const submitForm = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();
    console.log(formData);
  };

  return (
    <form onSubmit={submitForm}>
      <input name="name" value={formData.name} onChange={handleChange} />
      <input name="email" value={formData.email} onChange={handleChange} />
      <input name="password" value={formData.password} onChange={handleChange} />
      <button type="submit">Submit</button>
    </form>
  );
}
```

This still uses `onChange`, but only once for all inputs.

---

## Important note
If you truly want no `onChange` at all, then in React there is no clean native way to read form values without state or refs. The usual pattern is:
- `useState` for controlled inputs
- or `useRef` for uncontrolled inputs

Example with `useRef`:

```tsx
import { useRef, type FormEvent } from "react";

export default function LoginPage() {
  const formRef = useRef<HTMLFormElement | null>(null);

  const submitForm = (e: FormEvent<HTMLFormElement>) => {
    e.preventDefault();

    const formData = new FormData(formRef.current!);
    console.log(Object.fromEntries(formData.entries()));
  };

  return (
    <form ref={formRef} onSubmit={submitForm}>
      <input name="name" />
      <input name="email" />
      <input name="password" type="password" />
      <button type="submit">Submit</button>
    </form>
  );
}
```

This is the React-friendly way to get data from a form without `document.querySelector`, and it does not require `onChange` for each field.

> In short: use `FormData` + `ref` for no per-field `onChange`, or `useState` for full React-controlled input handling.
