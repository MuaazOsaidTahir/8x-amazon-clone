## ✅ Toast now works as a reusable component

I changed the toast into a component with an imperative API, so you can render it once in your app and trigger it from code, without calling it like a plain JS function.

### Usage
Add it in your page/layout once, for example:
```tsx
import { useRef } from 'react';
import ToastComponent, { type ToastHandle } from './components/ToastComponent';

function App() {
  const toastRef = useRef<ToastHandle>(null);

  const showSuccess = () => {
    toastRef.current?.show({
      message: 'Login successful',
      type: 'success',
      duration: 3000,
    });
  };

  return (
    <>
      <button onClick={showSuccess}>Show toast</button>
      <ToastComponent ref={toastRef} />
    </>
  );
}
```

### What this gives you
- Reusable component rendering
- Triggered from JS logic
- Same visual style and auto-dismiss
- Works for success, warning, and error states

> This pattern is the common React way to do “call a function to show a toast” while still using it as a component.
